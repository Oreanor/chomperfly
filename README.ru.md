# Chomperfly

*[English version](README.md)*

Небольшая онлайн-игра в 3D для 1–8 игроков прямо в браузере. Каждый игрок — червяк на большом фрукте, висящем в саду. Ползай по кожуре, грызи ходы внутри, расти и первым набери цель комнаты (**300, 500 или 1000 очков**, выбирается при создании): победитель отращивает крылья и улетает.

Сделано на Next.js, React и three.js, плюс небольшой Node-сервер с WebSocket для онлайна.

## Геймплей

- **На кожуре** червяк ползёт как гусеница-землемер: подтягивает хвост, выгибает спину, вытягивает перёд. Может встать на хвост и оглядеться.
- **Вгрызание** (левая кнопка мыши) уводит его внутрь фрукта. Там он движется змейкой и прогрызает ход. Фрукт вокруг становится полупрозрачным, а все ходы видны как стеклянные трубы.
- **Рост:** червяк растёт только пока грызёт мякоть. Путь длиной в диаметр фрукта даёт +50% к размеру. Очки = насколько вырос (+1% = 1 очко).
- **Победа:** первый, кто набрал нужные очки, взмывает над фруктом, у него выскакивают усики и две пары крыльев, он взрывается конфетти и улетает. У всех появляется окно победы, начинается новый раунд, все снова маленькие.
- **Прятки:** червяк на кожуре не видит червяка внутри фрукта, и наоборот. Таблички с именами видны сквозь фрукт, только когда вы в одном слое.
- **Укусы:** если боднуть другого червяка головой в бок, он замирает на 5 секунд. Лоб в лоб не считается.
- **Боты** занимают свободные места: ползают, оглядываются, вгрызаются, грызут, вылезают и тоже могут победить.

## Лобби и комнаты

После ввода имени попадаешь в лобби:

- **Список комнат:** название, карта (какой фрукт), игроков `n/макс`, кнопка **Войти**.
- **Создать комнату:** название, карта, максимум игроков (2–8), сколько ботов (0–3).

Комната живёт, пока в ней кто-то есть, и закрывается примерно через минуту после ухода последнего. Ходы и дырки живут вместе с ней. В комнате ⎋ возвращает в лобби.

## Управление

| Клавиша | Действие |
|---|---|
| **W** | вперёд (ползти по кожуре / грызть внутри) |
| **A / D** | поворот (внутри фрукта мышь тоже рулит, на кожуре мышь крутит камеру) |
| **S** | встать на хвост |
| **Пробел** | прыжок на хвосте (через паутину) |
| **ЛКМ** | вгрызться / грызть |
| **← / →** | облёт камеры |
| **↑ / ↓ / колесо** | камера ближе / дальше |
| **V** | сброс вида |
| **X** | рентген на кожуре (внутри включён всегда) |
| **R** | начать раунд заново для всех (с подтверждением) |
| **N** | настройки: имя, язык (RU/EN), тема |
| **H** | скрыть подсказку по клавишам |

Клик в игре захватывает мышь (Esc — отпустить).

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev          # разработка, http://localhost:3000
npm run build && npm start   # боевой режим
```

Сервер печатает адрес в локальной сети. Друг в том же Wi-Fi открывает его и заходит в твою комнату из лобби.

Чтобы позвать кого-то извне, проще всего бесплатно открыть туннель со своего ПК, например `cloudflared tunnel --url http://localhost:3000`. Чтобы игра работала без твоего ПК, нужен хостинг с постоянно запущенным Node-процессом и поддержкой WebSocket (VPS, Railway, Render…). Бессерверные платформы вроде Vercel не подойдут: они не держат WebSocket-соединения.

## Как добавить фрукт (карту)

1. Положи GLB-модель в `public/fruits/<имя>.glb`. Черенок должен смотреть вверх (+Y). Форма — «звёздная»: любой луч из центра пересекает поверхность один раз (яблоко, груша, слива, апельсин подходят; банан нет).
2. Опиши его в `lib/fruits.json`: цвет мякоти, семечки (вид, сколько, сколько скорости даёт каждое) или модель косточки. В лобби попадают только фрукты из этого файла.
3. По желанию добавь равнопрямоугольную панораму неба `public/sky/<имя>.jpg` (2:1). Самая яркая точка станет направлением солнца.
4. По желанию добавь отображаемое название в `lib/i18n.tsx` (`fruit.<имя>`) и `components/Lobby.tsx` (`FRUIT_NAMES`).

После этого карта появится в лобби. При загрузке модель центрируется и масштабируется, мелкие бугры сглаживаются, текстура перепекается в сферическую развёртку, и червяки ползают ровно по этой гладкой поверхности.

## Структура проекта

```
server.mjs              сервер Next.js + WebSocket: API лобби, комнаты, пересылка, укусы, победы, выбор ведущего
components/
  Game.tsx              оболочка: имя → лобби → игра
  Lobby.tsx             список комнат и «создать комнату»
  GameUI.tsx            интерфейс в игре и окна
  AccountDialogs.tsx    ввод имени и настройки
  ui/                   маленький UI-кит
lib/
  rules.json            правила, общие для игры и сервера (цели, размер к победе, бонус семечка, ступор, радиусы шариков)
  fruits.json           что у какого фрукта внутри (мякоть, семечки, косточка)
  protocol.ts           все сообщения, которые игра шлёт серверу
  net.ts                соединение WebSocket (с переподключением)
  game/engine.ts        3D-сцена, управление, камера, сеть, боты, победа
  worm/WormSim.ts       движение червяка: гусеница, вгрызание, рост, полёт
  worm/Bot.ts           мозги бота (играет через своё соединение)
  worm/Ants.ts          муравьи, коровки, пауки: считает один игрок (ведущий), рисуют все
  worm/wormView.ts      внешний вид червяка
  worm/constants.ts     настройки: размеры, скорости
  render/               материалы, ходы, дырки, небо-купол, семечки, паутина, эффекты
  apple.ts              форма фрукта для физики
  appleModel.ts         загрузка GLB, сглаживание, перепечатка текстуры
  bite.mjs              проверка укусов на сервере
  i18n.tsx, theme.tsx   языки и темы
```

Сеть: каждый игрок шлёт своего червяка ~15 раз в секунду; сервер пересылает и проверяет укусы, семечки и победы. Один игрок («ведущий», его выбирает сервер и передаёт другому, если тот замолчал) считает живность и шлёт её 10 раз в секунду; паутина уходит целиком раз в 4 с, а в промежутках — только новые кусочки. Игрок с медленной связью просто пропускает устаревшие обновления.

В режиме разработки в консоли браузера есть две команды: `__worm()` показывает состояние игры, `__wormFly()` проигрывает полёт победителя.
